라비 홍보 도우미 — 0.6.6 요청 주제·이미지·해시태그 수정 (2026-10-06)

사용법
1. 라비에게 「레이븐볼트 홍보글 써 줘」「내 가게 홍보」「독서 모임 홍보」처럼 요청한다.
   앱/지갑/프로그램은 앱, 가게/메뉴/오늘 특가는 가게, 그 밖에는 원문을 직접 주제로 쓴다.
   결과 위 「내 가게」「레이븐볼트 앱」「직접 주제」 칩을 바꾸면 다시 생성한다.
2. 앱의 현재 언어를 기본으로 쓰며 글 언어를 네 언어 중에서 고를 수 있다.
   「다시 쓰기」는 저장된 가게 정보를 다시 읽는다. 원문 요청은 AI에 그대로 전달한다.
3. 본문과 「해시태그」를 따로 편집한다. 「복사」는 합쳐 복사, 「태그만 복사」는 태그만 복사한다.
   X 2~4개, 인스타 8~15개, 카카오톡 0~3개, 동네 2~4개.
   한국어+영어는 항상 포함한다. 선택 언어 태그도 추가한다.
   짧은 채널은 가게 이름·업종·동네를 한 태그로 합쳐 개수 제한을 맞춘다.
   데이터에 없는 업종·동네는 만들지 않는다. 중복·공백·특수문자를 정리한다.
4. 「이미지 한 줄」을 편집하고 「공유 이미지 만들기」를 누른 뒤 「PNG 저장」한다.
   PNG 저장은 이미지 생성 후 켜진다. 사람이 직접 게시한다.

데이터·비용·그림
- src/ravi-promo-facts.json의 네 언어 사실표를 AI와 키 없는 앱 템플릿이 함께 쓴다.
  앱 홍보에는 가게/메뉴를 보내지 않는다. 사실표 밖 내용·수익 약속·가격 전망을 금지한다.
  사실표 밖 숫자·일부 약속 표현은 초안 거절 후 템플릿으로 돌아가고, 편집 중에는 경고한다.
- 가게 홍보는 공개 이름·소개·업종·동네·메뉴·가격·통화·영업시간·공개 URL만 쓴다.
  샘플/sample/예시 접두어, 샘플 표시, 기존 기본 예시 이미지의 메뉴를 제외한다.
  실제 메뉴가 없으면 가게 홍보에만 「메뉴를 먼저 등록하세요」를 표시한다.
  열쇠·복구 단어·매출·고객·결제 주소·사장/직원 QR 자격정보는 전달하지 않는다.
- QR은 저장된 주문 주소 우선. 없으면 앱은 언어별 ravenvault.ex.erci.se,
  가게는 등록된 가게 /s/ 주소 또는 활성 터널/폰 연결의 손님 페이지를 쓴다.
  가게에 아무 주소도 없으면 이미지 단추 옆에 구체적인 이유를 표시한다.
- 1080×1080 로컬 canvas: 라비 + 앱은 RavenVault/가게는 가게 이름 + 한 줄 + QR.
  그림 생성은 AI 키와 무관하다. 유료 이미지 API는 사용하지 않는다.
- AI는 사장 제공자 순서와 Lane::Owner 예산, 전송 전 permit.charge()를 유지한다.
  AI 키 없음/실패/잘못된 형식/앱 숫자 위반은 사실 기반 템플릿으로 돌아간다.
- X는 본문+태그를 합쳐 CJK 두 글자·URL 23글자로 280 이내로 계산한다.
  긴 가게 필드도 태그를 먼저 예약하고, 템플릿은 이름·가격 사실을 통째로 선택한다.

Git 포장
원래 worktree index.lock 쓰기가 Operation not permitted로 거부되었다.
/tmp의 GIT_INDEX_FILE과 임시 객체 저장소를 써서 의미 단위 커밋을 만들고
refs/heads/claude/promo-fix를 artifacts/promo-fix.bundle에 담는다.
기준은 588c8a4. 원래 worktree HEAD는 유지되고 수정 파일은 작업 폴더에 남는다.
push와 태그는 수행하지 않는다. bundle은 기준 커밋을 가진 저장소에서 가져온다.
