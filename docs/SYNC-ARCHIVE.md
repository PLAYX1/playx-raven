# 내 글은 내 컴퓨터에 — 쪽지 보관 · 지난 글 모으기 · 연결할 때 열쇠 확인

데스크탑(이 저장소)과 폰(`wt-rv-0918-phone`)이 함께 따르는 규칙. 11-08.

## 1. 쪽지 보관 (NIP-17 겉봉 kind 1059)

- 이 컴퓨터 릴레이(`src-tauri/src/relay.rs`)는 kind 1059 를 **`p` 태그가 이 컴퓨터 주인(이야기 이름, `relay::owner()`)일 때만** 받는다.
  남에게 가는 겉봉은 받지 않는다(디스크 채우기 방지). 크기 한도(32KB)는 그대로.
- 겉봉은 글쓴이가 1회용 열쇠이고 `created_at` 이 최대 이틀 앞당겨진다(NIP-59). 그래서
  - 「너무 오래된 글」(90일) 규칙은 주인 겉봉에 걸지 않는다(옛 쪽지도 보관).
  - 「미래 시각」 허용 폭은 다른 글과 같다(+15분). 바깥 지킴이는 이틀 겹쳐 읽는다.
  - 주인 겉봉은 남의 글 한도(5,000)에 세지 않고, 따로 **최대 20,000장**(넘치면 가장 오래된 겉봉부터 뺀다).
- 「내 글 지키기」 모으기(15분마다)는 바깥 릴레이에서 `{kinds:[1059], "#p":[주인]}` 도 쪽을 넘기며 끝까지 읽어
  **봉한 그대로** 저장한다. 데스크탑은 어디서도 겉봉을 풀지 않는다(릴레이·서버 쪽 복호화 없음, 내용을 다른 곳에 보내지 않음).
- 보낸 쪽지의 내 사본: 지갑 화면(`web/wallet.src.ts` `sendTalk`)과 폰(`core/talk/nip17.ts` `wrapMessage`) 모두
  상대 것 + 내 것(p=나) 두 장을 만든다. 데스크탑이 올리는 길(`nostrpub::targets()`)은 이 컴퓨터 릴레이를 맨 앞에 두므로
  내가 보낸 쪽지도 바로 보관된다.
- 쪽지함 읽기(`/api/nostr/query` → `nostrpub::nostr_query`)는 이미 이 컴퓨터 릴레이를 함께 읽는다 —
  공용 릴레이가 지워도 보관분이 보인다.

## 2. 지난 글 모으기 진행 표시

`relay_status` 에 아래 칸이 더해진다(데스크탑 화면 「내 글 서랍」이 읽는다). 전체 수는 알 수 없으므로 **모은 수만** 보여 준다.

| 칸 | 뜻 |
|---|---|
| `my_backfill` | `true` = 처음·이름이 바뀐 뒤·사흘 넘게 못 모은 뒤 옛 글까지 모으는 중 (쪽마다 바로 저장하므로 아래 두 수가 실시간으로 는다) |
| `my_notes` | 이 컴퓨터에 남은 내 글(kind 1) 수 |
| `my_dms` | 이 컴퓨터에 보관된 쪽지(나에게 온 겉봉) 수 |

## 3. 연결할 때 열쇠 확인 (「폰과 지갑 연결」, wallet-link v1)

공개 열쇠만 주고받는다. 필드 이름은 **`talk_pub`** (64자리 소문자 16진수, 이야기/nostr x-only 공개키).

### 폰 → 데스크탑: LinkAccept 본문에 선택 칸

```
{"rvwl1":"accept","s":{"body":{"v":1,"linkId":…,"phoneKey":…,"phoneAddresses":[…],"talk_pub":"<64hex>"},"sig":…}}
```

- 서명(`accept` 태그) 범위 안에 들어간다. 옛 데스크탑은 몰라도 서명은 그대로 맞는다(본문 전체를 다이제스트).
- 새 데스크탑: `talk_pub` 가 64hex 가 아니면 없는 것으로 친다.

### 데스크탑 → 폰: 새 메시지 `talk` (QR 제안에는 넣지 않는다 — 옛 폰의 `parseLinkOffer` 가 칸 수를 정확히 보기 때문)

사람이 「같아요」(confirm)를 누른 뒤 데스크탑이 보낸다(못 보내면 다음 확인 때 다시).

```
{"rvwl1":"talk","s":{"body":{"v":1,"linkId":"<64hex>","talk_pub":"<64hex>","at":<ms>},"sig":"<128hex>"}}
```

- 서명: `sha256("ravenvault-wallet-link-v1|talk|" + canonical(body))` 를 **데스크탑 연결 열쇠**(offer 의 `desktopKey`)로 BIP-340.
  (`signLinkTalk`/`verifyLinkTalk`, LinkSeen 과 같은 모양)
- 폰은 `linkId` 가 자기 연결이고 서명이 `desktopKey` 로 맞을 때만 쓴다. 옛 폰은 모르는 `t` 를 조용히 버린다.

### 화면

- 둘 다 있고 같으면: 「폰과 컴퓨터가 같은 이야기 이름이에요 — 글이 한곳에 모여요」
- 둘 다 있고 다르면: 「폰과 컴퓨터의 이야기 이름이 달라요. 같은 12단어로 맞추면 글이 한곳에 모여요」
- 한쪽이라도 없으면(옛 폰·이야기 이름 없음): 아무것도 안 보인다.

데스크탑 `wallet_link_list`/`wallet_link_inbox` 의 연결마다 `talkSame: true | false | null`.
