# Raven 현황 · 홈 개편 설계안 (RavenVault Desktop)

2026-10-09 · 설계 책임: Claude · 구현: GPT (아래 9장 과제 단위) · 상태: **대표 결정 대기 5건(10장) 외에는 확정**

대표 요청 요지: 「라비가 나와서 내 RVN 을 보여 주는 지금 홈은 좋다. 디자인을 더 좋게, 그리고 데스크톱 한 화면에서
노드 상태·네트워크 채굴 해시레이트·부자순위·자산 조회·블록/거래/주소 조회 — 레이븐 사용자가 찾는 것 전부.
별도 화면·버튼이 필요하면 그렇게.」

이 문서가 지키는 기존 원칙 (DESIGN.md·home-onescreen-report.md 에서 그대로):
- 돈 화면은 라비가 흩뜨리지 않는다. 금액·주소·승인은 움직이지 않는다.
- 가짜 숫자 금지. 모르면 「확인 못 함」이지 0 이 아니다. 가짜 진행률 바 금지.
- 내 지갑이 무엇을 들고 있는지는 바깥에 찍히지 않는다 (IPFS 는 `127.0.0.1:8080` 만).
- 사이드바로 나눈다. 한 페이지에 쌓지 않는다.

## 1. 정보 구조 판정

### 결론
| 무엇 | 어디 | 이유 |
|---|---|---|
| 라비 + 완료 잔액 + 보내기/받기 | **홈 (주인공, 그대로)** | 대표가 좋다고 한 부분. 매일 여는 이유. |
| 알림·할 일, 최근 거래, 오늘 매출 | 홈 (그대로, 우선순위만 재정렬) | 「내 일」. |
| 노드·해시레이트·블록·대기 거래·수수료·공급·반감기·가격 | **새 화면 「Raven 현황」** | 「세상 일」. 홈에 얹으면 잔액 카드가 밀려 한 화면이 깨진다 (1120×780 여유 10px). |
| 블록·거래·주소·자산 조회, 부자순위 | 「Raven 현황」 안의 탭 + 어디서나 쓰는 검색창 | 조회는 결과 화면이 넓어야 한다. 홈 카드 크기로는 해시 한 줄도 못 담는다. |
| 홈 → 현황 연결 | 홈 맨 위 **한 줄 띠 (Raven 띠)** | 지금 `<h1>홈</h1>` 줄(약 36px)을 대체 → **홈 높이 증가 0px**. |

- 새 화면은 사이드바 1차 메뉴. 위치는 「자산」 바로 아래. 돈이 나가는 버튼이 **하나도 없는 화면**이다
  (DESIGN.md 「자산 화면이 안전한 것은 보내는 버튼이 없기 때문」과 같은 이유). 라비는 이 화면에 나오지 않는다.
- 기존 「자산」(page-assets, 내 자산 보존·발행·맞교환)과 **합치지 않는다.** 그쪽은 「내 것을 지키는 곳」,
  새 탭은 「체인 위 아무 자산이나 찾는 곳」. 탭 이름을 「자산 찾기」로 해 이름 충돌을 피한다.

### 메뉴·탭 이름 (4개 언어)
| 열쇠(한국어 원문) | en | ja | zh |
|---|---|---|---|
| Raven 현황 (사이드바·제목) | Raven Network | Raven 状況 | Raven 概况 |
| 현황 | Overview | 概要 | 概览 |
| 탐색 | Explorer | エクスプローラー | 浏览器 |
| 자산 찾기 | Find assets | アセット検索 | 资产查询 |
| 부자순위 | Rich list | 保有ランキング | 富豪榜 |
| 노드 | My node | ノード | 节点 |
| 블록 높이·해시·거래·주소·자산 이름 | Block height, hash, txid, address or asset | ブロック高・ハッシュ・取引・アドレス・アセット名 | 区块高度、哈希、交易、地址或资产名 |

### 화면 안에서 탭을 쓰는가 — **쓴다. 5개.**
- 한 화면 무스크롤 조건에서 현황 카드 8장 + 조회 결과 + 부자순위 표를 동시에 담을 수 없다. 스크롤 대시보드는
  키오스크처럼 「한눈에」가 아니게 되고, 카드끼리 높이를 다툰다.
- 탭은 **질문 단위**다: 「지금 괜찮나」(현황) · 「이게 뭐지」(탐색) · 「이 자산 뭐지」(자산 찾기) ·
  「누가 많이 갖고 있나」(부자순위) · 「내 노드 왜 이래」(노드).
- **검색창은 탭 바깥(화면 머리)** 에 하나. 어느 탭에서 쳐도 결과 종류에 맞는 탭으로 이동한다 (5장).
- 탭 = `role="tablist"`, 좌우 화살표 이동(roving tabindex), `Alt+1~5` 직행. 마지막 탭은 기기 저장소에 기억
  (try/catch, 없으면 「현황」).

### Raven 띠 내용 (왼쪽부터, 각 칸은 하나의 버튼 → 현황 화면의 해당 카드로 이동·포커스)
```
[● 내 노드 동기화됨 · 블록 4,6xx,xxx · 2분 전] [해시 6.1 TH/s] [대기 1,204건] [1 RVN ₩25.3 외부·1분 전]   [Raven 현황 →]
```
- 높이 36px, 글자 15px, 칩 사이 8px. 값 못 읽으면 칩 안에 「확인 못 함」. 외부 값(가격)은 `외부` 꼬리표가 항상 붙는다.
- 외부 데이터가 꺼져 있으면 가격 칩 자체를 **숨긴다** (꺼둔 것을 「확인 못 함」으로 보여 불안하게 하지 않는다).
- 노드 꺼짐/동기화 중일 때는 띠 첫 칸이 노란색 「동기화 중 63% · 남은 블록 12,000」 하나만 보이고 나머지 칩은 숨긴다
  (동기화 중 해시레이트는 옛 높이 기준이라 오해를 부른다).

### 카드별 정의 (모든 숫자 카드는 아래 「출처줄」 필수)
- **출처줄** 형식: `내 노드 · 12초 전` / `외부 · 업비트 · 1분 전` / `계산값 · 발행 일정 기준`.
  13px, muted 색(대비 4.5:1 이상). `data-source`·`data-updated` 속성으로 시험에서 검사.
- **내 노드**: 상태(동기화됨/동기화 중 n%/꺼짐/응답 없음), 연결 수(나감·들어옴), 버전, 블록 정리(prune) 여부,
  색인 상태 3개(자산·주소·거래) 작은 점. 누르면 「노드」 탭.
- **네트워크 해시레이트**: `getnetworkhashps` 120블록 기준 값 + 24시간 스파크라인(24점, 60블록 간격 과거 높이 표본).
  단위 자동(GH/TH/PH). 난이도. **내 노드가 동기화 안 됐으면 카드 전체를 「동기화 끝나면 보여요」 빈 상태로.**
- **블록**: 높이, 마지막 블록 경과, 최근 30블록 평균 블록 간격(헤더 시간차, 목표 60초 병기).
- **최근 블록**: 6줄(1280×720 은 5, 1024×640 은 4). 높이·경과·거래 수·크기. 줄 클릭 → 탐색 탭 블록 보기.
- **대기 거래 · 수수료**: `getmempoolinfo` 건수·용량·최소 수수료, `estimatesmartfee` 2/6/24 블록. 추정 실패 시
  「추정 불가 (거래 기록 부족)」. 스파크라인은 **이 창을 연 뒤 메모리 표본**만 (저장 안 함, 문구로 명시).
- **공급 · 반감기**: 기본은 **계산값** (보상 5000 → 2,100,000블록마다 절반, mining.rs 와 같은 식 — 공용 함수로 뽑을 것).
  「실측하기」 버튼 → `gettxoutsetinfo` (수 분, 중지 버튼 필수, 진행률 바 없이 「세는 중 · 중지」). 실측값은 24시간 캐시.
  반감기 남은 시간은 「≈ … (블록 60초 가정 추정)」 꼬리표.
- **RVN 가격 [외부]**: 기존 `rvn_rate` 재사용(통화 = 가게 통화 설정). 24시간 변동은 **중립색**(빨강/초록 금지 — 투자 신호처럼 읽힘).
  외부 꺼짐 → 카드 대신 「외부 데이터를 꺼 두었어요 · 설정에서 켜기」.
- **내 자산 줄**: `listmyassets` 종 수 + 기존 보존 상태 요약. 금액은 표시하지 않음 (금액은 지갑·자산 화면 몫).

| 부자순위 (외부) | 탭을 열 때만, 캐시 6시간, 수동 새로고침 최소 5분 간격 | |
| 자산 보유자 | 요청 시, 자산별 캐시 10분 | |

- **멈춤 규칙**: 다음 중 하나면 타이머를 전부 해제(일시정지가 아니라 `clearTimeout`): 다른 사이드바 화면으로 이동,
  `document.hidden`, 앱 잠금/쉬는 화면(idle) 진입. 돌아오면 **즉시 1회** 읽고 재개. 홈 띠는 홈이 보일 때만 20초(기존 홈 주기에 합류).
- 동시 요청 금지: 같은 명령은 앞 요청이 끝나기 전 다시 부르지 않는다(in-flight 플래그). 노드가 느리면 주기가 자연히 늘어난다.

- **검색**: 입력 250ms 뒤 `listassets "<대문자>*" true 20 0` (내 노드). 자동 대문자화, 소문자 입력 시 「자산 이름은 대문자예요」 안내.

- **보유자**: 개수는 `listaddressesbyasset NAME true` (총계만). 상위 10명은 러스트에서 전체를 받아 정렬하되
  **5,000명 초과면 상위 표를 만들지 않고** 「보유자가 많아 순위를 만들지 않았어요 (n명)」. 내 주소 꼬리표는 러스트가
  `validateaddress`/지갑 주소 목록으로 **로컬 판정**.
- **자산 색인 꺼짐**: 보유자 칸 = 「이 노드는 자산 색인이 꺼져 있어요 · 켜면 재색인 몇 시간」 + 설정 「이 컴퓨터」 이동 단추.
  외부로 대신 묻지 않는다 (아래 6장 경계).
- **IPFS 미리보기**: `127.0.0.1:8080` 만. JSON/텍스트(앞 4KB, 이스케이프)·이미지만 인라인. 그 외·PDF 는 기존 sandbox iframe 규칙.
  로컬 IPFS 꺼짐 → 「이 컴퓨터 사진 보관함이 꺼져 있어요」. 공개 게이트웨이 단추 **만들지 않는다.**
- **제한 자산(`$`)**: `getverifierstring` 의 검증 문자열 표시, 주소 입력 시 `checkaddressrestriction`/`isaddressfrozen`.
  **자격(`#`)**: `listaddressesfortag` 개수. 둘 다 읽기만.
- **내 자산**: `listmyassets` 이름 목록. 수량은 보이지 않고 「보유」 표시만 (금액은 지갑 화면). 이름 클릭 → 같은 상세.
- 「최근 찾은 자산」은 기기 저장소에만 10개, 설정에서 지우기/끄기.

## 5. 검색창 (한 칸으로 전부)

### 판별 순서 (클라이언트에서 모양 판정 → 러스트 `explore_query` 가 실제 확인)
| 입력 모양 | 판정 | 확인 RPC |
|---|---|---|
| 숫자만 (0 ≤ n ≤ 현재 높이) | 블록 높이 | `getblockhash` → `getblock` |
| 숫자만 (현재 높이 초과) | 「아직 없는 블록 (현재 #…)」 | — |
| 64자리 16진수 | 블록 해시 **또는** 거래 | 병렬: `getblockheader` / 지갑 거래 `gettransaction` → 대기 거래 → `getrawtransaction` |
| `R`/`r` 시작 34자 base58 (테스트넷 `m`/`n`/`2`) | 주소 | `validateaddress` (isvalid·ismine) |
| 대문자·숫자·`._/#!$~` 조합, 3자 이상 | 자산 이름 | `getassetdata` |
| 나머지 | 찾지 못함 | 자산 접두 검색 제안 3개 |

- 숫자만인 입력이 자산 이름일 수도 있으면 결과 아래 「자산 이름으로도 찾기」 칩.
- 입력 중 아래로 드롭다운: 「블록 #… 으로 이동」 같은 **판정 결과 미리보기 1줄** + 자산 접두 제안 최대 5. 위/아래 화살표·Enter·Esc.
- `Ctrl/⌘+K` 와 `/` 로 어디서나 포커스 (입력란 안에서는 `/` 무시). 결과 종류에 맞는 탭으로 이동하고 URL 해시
  `#network/block/123` 식으로 남겨 뒤로가기 지원 (기존 showPage 와 충돌 없는 범위에서).

### 결과 화면 (탐색 탭 안, 오른쪽 넓은 패널 · 왼쪽은 최근 블록/검색 기록)
- **블록**: 높이, 해시(가운데 생략 + 복사), 시간(현지 시각 + 경과), 거래 수, 크기, 난이도, 이전/다음 단추, 거래 목록 25개씩.
- **거래**: 확인 수(0 = 「대기 중」), 포함 블록, 시간, 입력·출력(자산 이동은 자산 이름 + 수량 줄 따로), 수수료는
  **이전 출력을 읽을 수 있을 때만** 계산하고 아니면 「수수료 계산 불가 (거래 색인 필요)」. 내 지갑 거래면 「내 지갑」 꼬리표.
- **주소**: RVN 잔액(`getaddressbalance`), 자산 잔액(`listassetbalancesbyaddress`), 거래 목록(`getaddresstxids` 역순 25개씩).
  내 주소면 「내 지갑 주소」 꼬리표. 주소 색인 꺼짐 → 「주소 색인이 꺼져 있어요」 + 설정 단추.
- **색인이 없어 못 찾을 때의 외부 탐색기 단추**: 「외부 탐색기에서 열기 — 이 조회가 그 사이트에 보입니다」.
  기본 브라우저로 열 뿐 앱이 대신 부르지 않는다. **ismine 인 주소·내 지갑 거래에는 이 단추를 그리지 않는다.**
- 해시·주소는 `translate="no"`, 고정폭 글꼴, 가운데 생략(앞 10 · 뒤 8), 복사 단추(36px). 사용자 데이터라 번역 대상 아님.

## 6. 부자순위

### 사실
- 레이븐 코어에는 RVN 부자순위 RPC 가 없다. `addressindex` 가 있어도 「전체 주소를 잔액순으로」 묻는 명령이 없다.
- **자산** 부자순위는 내 노드로 된다 (`listaddressesbyasset`, 자산 색인 필요) → 4장 상위 보유자와 같은 엔진.

### 결정
| 안 | 장점 | 단점 | 판정 |
|---|---|---|---|
| A. 외부 공개 API, 캐시 6시간 | 바로 됨, 가벼움 | 외부 의존·제공처 바뀜·IP 노출 | **기본 채택** |
| B. 내 노드로 전 UTXO 훑어 직접 색인 | 완전한 자립 | 수십 GB 훑기·수 시간·저사양 PC(8GB) 원칙 위배, 상시 갱신 비용 | 이번엔 안 함. 「나중에」 후보로만 |
| C. ElectrumX(이미 선택 기능 있음) 위에서 집계 | 자립 | ElectrumX 도 잔액순 목록을 안 줌 | 불가 |

- 탭 구성: 위에 토글 `[RVN] [자산]`. RVN = 외부(A), 자산 = 내 노드. 표: 순위·주소(가운데 생략)·보유량·비중%. 100위까지, 25개씩.
- **출처 꼬리표 (정확한 문구)**:
  - 표 머리: `외부 데이터 · <제공처 이름> · 6시간마다 · 마지막 갱신 10월 9일 14:02`
  - 표 아래: `이 순위는 외부 사이트가 집계했습니다. 이 앱이 검증하지 않았습니다. 거래소 지갑이 섞여 있습니다.`
  - 자산 모드: `내 노드 · 자산 색인 · 3분 전`
  - en: `External data · <provider> · every 6 h · updated …` / `Ranked by an external site. Not verified by this app. Includes exchange wallets.`
  - ja: `外部データ · <提供元> · 6時間ごと · 最終更新 …` / `外部サイトの集計です。このアプリは検証していません。取引所のウォレットを含みます。`
  - zh: `外部数据 · <来源> · 每6小时 · 最后更新 …` / `由外部网站统计,本应用未验证,包含交易所钱包。`
- **내 주소 표시**: 받은 목록과 내 지갑 주소를 **기기 안에서** 비교해 「내 주소」 꼬리표. 내 주소를 외부로 보내 조회하지 않는다.
- **프라이버시**: 외부 요청에는 주소·txid·자산 이름 등 **사용자 입력이 하나도 실리지 않는다** (고정 URL 만). 러스트 쪽에서 강제
  (요청 URL 화이트리스트, 질의 문자열 없는 고정 경로). 외부 요청은 탭을 열었을 때만, 백그라운드 사전 로딩 없음.
- 제공처: 공개 탐색기 2곳을 어댑터로 두고 실패 시 다른 곳 (구체 주소는 구현 과제 B 에서 **응답 형식·이용약관을 확인한 뒤**
  고정 — 이 문서는 확인 안 된 주소를 적지 않는다). 둘 다 실패 → 마지막 캐시를 「6시간 지난 자료 · 마지막 갱신 …」 꼬리표와 함께,
  캐시도 없으면 「지금은 외부 순위를 가져올 수 없어요」 빈 상태.
- 설정 「이 컴퓨터」에 스위치 하나: **「외부 공개 데이터 쓰기 (가격 · 부자순위)」**. 끄면 외부 요청 0건 (가격 포함).

- **상태 세 가지**:
  - 불러오는 중: 숫자 자리에 같은 폭의 옅은 막대 (깜빡임 애니메이션 없음, 1초 넘으면 「읽는 중…」 글자).
  - 빈 상태: 이유 한 문장 + 할 수 있는 일 단추 하나 (「색인 켜기」·「노드 켜기」·「설정에서 켜기」). 0 을 쓰지 않는다.
  - 오류: 「확인 못 함 · 다시 시도」 + 출처줄에 마지막 성공 시각. 마지막 값은 지우지 않고 흐리게(70%) + 「n분 전 값」.
- **움직임 예산**: 탭 전환 120ms 페이드, 숫자 바뀜 애니메이션 없음(돈·숫자는 움직이지 않는다), 새 블록 도착 시 최근 블록
  첫 줄 배경만 1회 400ms 옅게. `prefers-reduced-motion` 이면 전부 0.
- **어두움**: 기존 `data-theme` + `prefers-color-scheme` 2중 규칙 그대로 복제. 스파크라인·상태 점도 토큰만 사용.
- **만들지 않는 것**: 캔들 차트·가격 그래프, 흐르는 시세 띠, 게이지/도넛, 빨강·초록 등락 색, 「수익」·「손익」 표시,
  지도/3D 지구본, 이 화면 안 라비·말풍선, 알림 소리, 자동 외부 조회, 공개 IPFS 게이트웨이 링크, 진행률 퍼센트 바.
- **문구 번역**: 사전(dict.ts)은 「값이 섞인 문장」을 못 옮긴다. 그래서 숫자는 항상 별도 `<span>` 에 두고 라벨만 사전 열쇠로
  (`<span>연결</span> <b>12</b>`). 새 라벨은 전부 `src/network-copy.ts` 에 4개 언어로 모아 사전에 등록.

### 검증 계획 (C·D 공통 하네스, `scripts/check-sales-browser.mjs` 방식)
- 실제 Chrome(puppeteer-core) · 모든 네트워크 요청 abort · `invoke` 를 픽스처 맵으로 대체 · 호출 기록 저장.
- 뷰포트 4 × 테마 2 × 언어 4 = 32 조합, 각 조합에서 상태 6개: 정상 / 노드 꺼짐 / 동기화 중 / 색인 꺼짐 / 외부 꺼짐 / 외부 실패(캐시).
- 단언:
  1. 1280×720 이상 현황 탭: `#page-network` 와 문서 모두 세로 스크롤 없음 (`scrollHeight <= clientHeight`). 1024×640 은 현황 탭 무스크롤, 다른 탭은 내부 목록만 스크롤 허용.
  2. 모든 크기·탭에서 가로 넘침 0 (요소별 `scrollWidth > clientWidth` 검사, 해시·긴 번역 포함).
  3. `[data-metric]` 마다 `[data-source]`·`[data-updated]` 가 비어 있지 않음. 외부 값엔 「외부」 꼬리표 존재.
  4. 「없음」 픽스처에서 지표 칸 텍스트가 `/^0([.,]0+)?$/` 이 아님 + 정해진 빈 상태 문구 존재.
  5. 단추·탭·칩 높이 ≥ 36px, 계산된 글자/배경 대비 ≥ 4.5 (알파 합성 반영).
  6. Tab 키 순서: 검색창 → 탭 → 카드 순 (양수 tabindex 0개).
  7. 폴링 정지: 가짜 타이머로 `document.hidden=true` + `visibilitychange`, 또는 다른 화면 이동 후 60초 진행 → invoke 호출 0건. 복귀 시 즉시 1회.
  8. 외부 꺼짐 상태에서 `public_*`·`rvn_rate` 호출 0건. 어떤 `public_*` 호출 인자에도 픽스처 지갑 주소·txid 가 없음.
  9. 검색 판별: 높이·초과 높이·블록 해시·txid·주소·자산·`$`/`#`/`!`/`~`·쓰레기 입력 각 1건이 올바른 탭/빈 상태로 감.
- 스크린샷: 32조합 × 정상 상태를 `docs/handoff/network-captures/` 에 저장해 사람이 눈으로 확인.
- 러스트: `cargo test explorer publicdata`. 기존 `check:pre-release` 에 새 하네스 연결.

## 10. 위험과 대표께 여쭐 것 (각 항목 권장 기본값 포함)

1. **RVN 부자순위를 외부에서 받아도 되나** — 외부에 우리 IP 와 「이 앱을 쓴다」는 사실이 남는다.
   **권장: 부자순위 탭을 처음 열 때 한 번 「외부에서 가져오기」 단추로 동의 → 이후 자동. 가격은 지금처럼 켜짐.** 설정에서 둘 다 끌 수 있음.
2. **거래 조회용 거래 색인(txindex) 스위치를 추가할까** — 켜면 재색인 몇 시간·디스크 증가·블록 정리와 함께 못 씀.
   **권장: 「이 컴퓨터」 설정에 스위치로 추가하되 기본 꺼짐, 기존 재색인 안내 흐름 재사용.** 꺼져 있으면 내 지갑·대기 거래만 조회.
3. **사이드바 자리와 이름** — 새 1차 메뉴가 하나 늘어난다. **권장: 「자산」 바로 아래, 이름 「Raven 현황」.** (「더 보기」 안에 넣으면 대표님이 못 찾으셨던 「나눠주기」 사례 반복)
4. **외부 제공처 선정** — 공개 탐색기 API 는 예고 없이 바뀐다. **권장: 두 곳 어댑터 + 장애 넘김, 과제 B 착수 시 이용약관·응답 형식 확인 후 대표께 이름만 보고.**
5. **공급량을 계산값으로 보여도 되나** — 소각분을 반영하지 않는다. **권장: 계산값을 기본으로 「계산값 · 발행 일정 기준」 꼬리표, 「실측하기」 수동 단추로 노드 실측(수 분)을 제공.**
