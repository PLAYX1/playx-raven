# 데스크톱 첫 실행 팝업 순서 수리

2026-10-06. 기존 브랜치 HEAD를 부모로 이번 수정만 임시 인덱스로 분리했다. 기존 음성·게임 등 미커밋 작업은 작업 디렉터리에 보존한다.

현재 작업트리의 `HEAD.lock` 생성이 환경 권한으로 거부되어 브랜치 포인터는 변경하지 못했다. 완성된 커밋은 `refs/deliveries/firstrun`에 보존하고 `artifacts/firstrun.bundle`로 전달한다. 공유 인덱스는 바이트 단위 해시가 동일하다.

## 적용한 흐름

앱 시작 → 라비 비행 → 착지 완료 → 인사·질문 말풍선. 대화창은 라비 또는 이야기하기 단추를 누를 때만 열린다. 인사 만료는 말풍선을 닫기만 한다. 저장된 대화창 열림 상태와 이전 라비 페이지는 자동 복원하지 않고, 대화창 크기는 유지한다.

`data-ravi-arriving`을 초기 HTML부터 설정해 첫 페인트의 겹침도 막는다. 클릭·활성화 키·공유 확인창·QR·신고·키 입력 요청은 착지 완료까지 큐에서 기다린다. 애니메이션 종료가 착지를 알리고, 이벤트가 없는 환경은 2.1초의 보수적인 대체 시간을 쓴다. 인사를 끈 경우에는 즉시 큐를 해제한다. 인사 시작 중복 호출로 큐가 일찍 풀리지 않는다.

휴대폰 연결 카드는 설정·지갑의 **휴대폰 연결** 단추로만 펼친다. QR 생성은 그 카드의 **폰 연결 QR 보이기**를 눌러야 한다. 폰 요청 조회는 알림만 갱신하며, 손님 QR 요청을 자동으로 열거나 완료 처리하지 않는다. 알림은 실제 대기 요청이 있을 때만 나오고, 누르면 설정의 연결 단추로 이동한다.

## 팝업·모달 전수 조사

조사 범위: 데스크톱 HTML의 고정 레이어·sheet·dialog, 생성형 UI, DOMContentLoaded·주기 조회·페이지 복원 진입점, 상주 라비 창. 일반 페이지 안의 상태 문구는 모달이 아니다.

| 화면 / 진입점 | 수정 후 규칙 |
| --- | --- |
| 손님 QR `#qrwrap` | 폴링 자동 열기 제거. 기존 가게 QR 단추·라비의 명시적 QR 요청·직접 연 폰 요청으로만 표시. 비행 중 요청은 큐 대기. |
| 휴대폰 연결 `#rvp-card`, `#rvp-qrarea` | 설정·지갑 연결 단추로 카드 표시, 카드 QR 단추로 QR 생성. 처음에는 둘 다 숨김. |
| 폰 연결 승인 `#rvp-pending`, 요청 상세 `#rvp-detail` | 연결 카드를 직접 연 상태에서 확인. 연결·거절·요청 열기도 직접 선택. |
| 폰 요청 알림 `#rvp-notice` | 실제 요청이 있을 때만 비침투 알림. 착지 전 숨김. 자동 QR·승인·페이지 이동 없음. |
| 라비 대화 `#ravi-panel`, 이전 `#chat` | 열림 상태 복원 및 인사 타이머의 자동 열기 제거. 사용자 선택만 허용. |
| 비행 인사 `.ravi-arrival` | 시작 시 허용되는 유일한 연출. 말풍선은 착지 뒤 표시, 만료 시 대화창을 열지 않음. |
| AI 키 `#ravi-key` | 키 없음으로 자동 표시하지 않음. 키 단추·명시적인 라비 요청으로만 열고 비행 중에는 지연. |
| AI 정보 동의 `.ravi-privacy` | 사용자가 AI 대화를 보낼 때만 동의 확인. 시작 시에는 설정 카드만 준비. |
| 용도 선택 `#hello` | 첫 실행 자동 표시 제거. 설정의 기존 지갑·돕기·장사 선택 사용. |
| 초기 장치 설정 `#onboard` | 자동 표시 제거. 설정의 **초기 설정** 단추에서만 실행. |
| 공통 입력·확인·알림 `#askwrap` | `ask/sure/choose/say` 모두 착지 후 실행. 기존 사용자 승인 순서는 유지. |
| 백업 안내 `showBackupReminder` | 받기·대화 전송 등 기존 사용자 동작에서만 확인. 비행 중 공유 확인창 대기. |
| 복구 단어 확인 `#sdw` | 지갑·백업의 확인 단추로만 실행. 시작 시 단어 표시 없음. |
| 복구 진행/중단 `#wrs` | 일반 진입은 사용자 동작. **이미 중단된 복구 때문에 지갑 시작이 막힌 경우만** 착지 후 기존 복구 안전 안내 허용. 단어 입력이나 복구 실행은 사용자 선택. |
| 송금 검토 `#send-review`, `#rv-send-card`, `#phone-tx-send` | 사용자 준비·검토 흐름만 유지. 비행 중 전경 표시 차단. 시작 시 송금창 열기 없음. |
| 발행 `#wiz`, 판매 `#sellsheet`, 회원 `#msheet` | 기존 사용자 단추에서만 실행. 비행 중 단추 요청은 큐 대기. |
| 문제 신고 `#rpwrap` | 신고 단추·다섯 손가락 제스처 요청도 착지 후에만 표시. |
| 파일 선택·저장·드롭 처리 | 사용자 동작만 유지. 비행 중 클릭과 native drop-files 처리를 지연. |
| 업데이트 `#upnag`, `#up-box` | 자동 확인은 페이지 안 상태·단추만 갱신. 설치 확인은 직접 누른 뒤. |
| 주문·입금·페이지 도움 `#neworder`, `#live-note`, `#ravibub`, `#dropveil` | 비행 중 겹침 차단. 기존 신규 사건 판정·사용자 도움 요청 유지. |
| 상주 라비 `#bubble`, `#preferences` | 시작 시 닫힘. 설정 상태의 bubble 복원 제거, 사용자 열기·native 이벤트는 착지 후 처리. 초기화 실패도 창을 자동 펼치지 않음. |
| 게임 모의 구매 `dialog` (별도 진행 중인 작업) | 게임을 직접 여는 단추가 전제. 공통 비행 가드가 시작 중 단추 실행 및 dialog 표시를 차단. 해당 기능 소스는 이번 커밋에 포함하지 않음. |

## 검사와 제한

- `npm run check:pre-release`: 빌드, TypeScript, preflight, 새 첫 실행 검사 통과. release workflow에 연결.
- `scripts/check-firstrun.mjs`: 실제 운영 컨트롤러를 합성 DOM·시계·RPC로 실행. 첫 실행/재실행 × 키 없음/있음 4조합, 저장된 열린 패널, 이전 라비 페이지, 비행 중 클릭, 착지, 18초 만료, 인사 끄기, 중복 시작, 공통 확인창 4종, 요청 없음/연결 요청/손님 QR 요청 검사 통과.
- 같은 스크립트의 `--browser`: dist 전체 앱을 메모리 요청 대역으로 실행하고 매 프레임 팝업을 관찰한다. 실제 지갑·AI·메인넷에 연결하지 않는다. 현재 환경에서는 Chrome 프로세스 시작이 거부되어 미검증이다.
- 기존 스크립트 포함 52개 검사 작업: 36개 통과, 의도적 변이 검사 1개는 기대한 실패로 방어 동작 확인, 15개는 실행 환경 제약으로 완료하지 못했다. 설치 프로그램 검사는 `CARGO_NET_OFFLINE=true` 재시도로 통과했다.
- Rust 전체: **757 통과 / 7 실패 / 13 ignored**. 실패 7개는 루프백 바인딩·소켓을 요구하며 현재 sandbox의 `EPERM` 제한에 걸린다. 복구 안전 하네스 23개와 백업 안전 15개는 통과했다.
- 브라우저·로컬 HTTP/노드 fixture 검사는 Chrome 실행 및 `127.0.0.1` 바인딩 권한 제한, 일부 기존 fixture 프로필 충돌로 막혔다. 이 항목들을 통과로 표시하지 않는다. 상세 목록: `artifacts/firstrun/checks.json`, Rust 목록: `artifacts/firstrun/cargo.json`.
- 커밋 예정 트리를 별도 임시 디렉터리로 추출해 배포 전 검사·패널·라비 상태 검사도 통과했다. 다른 진행 중인 변경을 포함하지 않아도 이번 수정이 빌드됨을 확인했다.

실제 송금·메인넷 거래는 수행하지 않았다. 새 검사·보고서에는 시드·토큰·비밀번호·대화 내용을 기록하지 않는다. **전체 검사 통과 조건은 환경 제약 때문에 아직 충족되지 않았으며 배포 승인을 의미하지 않는다.**
