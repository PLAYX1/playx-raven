## 실제 앱 브라우저 하네스

[check-home-browser.mjs](../../scripts/check-home-browser.mjs)는 `npm run build` 결과 `dist`의 HTML·JS·CSS를 변형 없이 제공합니다. 원본 HTML을 다시 조립하거나 렌더 함수만 추출해 화면을 만들지 않습니다. 임시 프로필을 사용하고 정적 서버를 `127.0.0.1` 포트 0에 묶으며 실행 후 닫습니다.

`evaluateOnNewDocument`로 Tauri invoke, callback, event, window 메타데이터를 먼저 주입합니다. fixture는 잠금 해제 상태, 42.125 RVN, 미확정 입금, 거래 8건, 자산 3개, AI 제공자 1개의 사용 가능 여부입니다. 자격증명 값은 만들지 않습니다. 인사 비활성화·한국어·테마를 정상 저장 설정으로 지정합니다. 실제 앱이 fixture를 소비하고 잔액·거래·라비 상태를 그릴 때까지 기다립니다.

외부 요청은 request interception으로 차단합니다. 이 실행의 정적 서버 origin으로 향하는 정적 리소스만 허용하고 fetch/XHR도 차단합니다. WebSocket/WebTransport 및 서비스 워커 우회도 방지합니다. native 동작은 실행하지 않습니다. 앱 시작 시 기존 코드가 요청하는 백업·가게 공지 등도 메모리 응답만 돌려줍니다. 알 수 없는 명령은 성공으로 위장하지 않고 거부·기록합니다. IPC 인자는 기록하지 않습니다.

16개 경우마다 다음을 JSON에 기록하고 첫 화면 PNG를 저장하도록 구현했습니다.

- 문서·본문·홈 그리드·보이는 내부 스크롤 영역(사이드바 포함)의 scroll/client 크기와 세로·가로 차이.
- 잔액, 보내기·받기, 최근 거래, 라비 상태·한마디·대화 단추, 알림·잠금·가게 요약의 경계·첫 화면 가시성.
- 조상에 의한 잘림, 다른 요소에 의한 가림, 카드 밖으로 나온 내용, 조작 크기, 계산된 글자 대비.
- 작은 창 더 보기의 Enter/Tab 동작, DOM에 맞는 키보드 순서, 라비 대화창 종료 후 초점 복귀.
- 금액·거래 수·AI 설정 등 fixture 소비, 비밀 표시 영역 비어 있음, 미처리 브라우저 오류.

변경 후 검사는 넘침 0px, 핵심 가시성, 최소 36px, 대비 4.5:1 중 하나라도 실패하면 종료 코드 1입니다. 변경 전 `--baseline`은 원래 넘침을 그대로 기록하며 레이아웃 실패를 허용하지만 로드 실패는 성공 처리하지 않습니다. PNG는 전체 페이지를 축소하지 않는 viewport 캡처입니다. 빌드 HTML과 엔트리 JS/CSS의 해시도 함께 기록합니다.
