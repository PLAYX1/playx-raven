# 릴레이 나누기 (RavenVault, 11-08 설계 — 데스크탑·폰·웹 공통 규약)

목표: 내 글은 내 컴퓨터 릴레이로 살아 있고, 레이븐볼트 데스크탑끼리 서로 릴레이가 되어 N100·공개 릴레이가 막혀도 글이 돈다.

## 1. 내 릴레이 주소 알리기 (NIP-65)
- 데스크탑에서 「릴레이 나누기」를 켜고, 바깥 주소가 있고(터널: 내장 cloudflared/「바깥에서 열기」), **바깥 주소로 스스로 접속해 REQ→EOSE 왕복이 되는 것**을 확인한 때에만 알린다.
- 이야기 열쇠로 kind 10002 를 올린다:
  - `["r", "<내 wss 주소>"]` (읽기·쓰기 둘 다 = 표지 없음)
  - 우리가 쓰는 기본 릴레이들도 `["r", ...]` 로 같이 적는다(N100 wss://playx.taile277f6.ts.net/relay, wss://relay.primal.net, wss://nos.lol, wss://relay.damus.io)
  - `["t", "ravenvault-relay"]` — 레이븐볼트 데스크탑 릴레이라는 표(찾기용)
- 주소가 바뀌면(임시 터널) 다시 올린다(10002 는 덮어쓰기형). 끄면 내 주소를 뺀 10002 를 다시 올린다.

## 2. 주소 검사 (모든 클라이언트 공통, 이것을 통과한 주소만 접속)
- `wss://` 만. 호스트는 DNS 이름(IP 숫자 주소 금지), localhost·*.local·*.internal·*.lan 금지, 포트는 없거나 443, 전체 길이 ≤ 200, 경로 ≤ 64.
- 한 사람의 10002 에서 최대 3개만 쓴다. 우리 기본 릴레이와 같은 주소는 중복 제거.

## 3. 이웃 데스크탑 찾기 (데스크탑)
- `{kinds:[10002], "#t":["ravenvault-relay"], since: 14일 전}` 를 기본 릴레이들에 묻는다(6시간마다).
- 검사(2절) 통과 + 접속 시험(REQ→EOSE 5초 안) 통과한 것 중 **최대 8곳**을 이웃으로 둔다(무작위로 섞어 고름). 내 주소는 뺀다.
- 내 이야기 글(kind 0·1·40·41·42·5)을 올릴 때 이웃에도 같이 보낸다(기다리지 않음, 실패 무시).
- 이야기·피드를 읽을 때 이웃도 추가 출처로 묻는다(기존 기본 릴레이 + 이웃, 늦은 곳은 기다리지 않음).

## 4. 글쓴이 릴레이에서 읽기 (outbox — 폰·웹·데스크탑)
- 방·피드·사람 카드에 보이는 글쓴이들의 kind 10002 를 받아 그 사람 `r` 주소(검사 통과, 사람당 ≤ 2)에서도 그 사람 글을 묻는다.
- 추가 연결은 동시에 ≤ 6곳, 5초 타임아웃, 6시간 기억. 설정 「이웃 릴레이에서도 읽기」(기본 켬)로 끌 수 있다.
- 안내 문구(설정 칸 아래): 「다른 사람 컴퓨터 릴레이에 연결하면 그 주인이 내 인터넷 주소(IP)를 볼 수 있어요. 공개 릴레이도 마찬가지예요.」

## 5. 내 글 다시 올리기 (데스크탑)
- 켜져 있는 동안 6시간마다: 내 컴퓨터 릴레이에 있는 **내 열쇠의** 최근 30일 글(kind 0·1·40·41·42) id 를 기본 릴레이들에 `{ids:[...]}` 로 묻고, 없는 곳에 원본을 다시 보낸다.
- 내가 지운 글(내 kind 5 가 가리키는 id)은 절대 다시 올리지 않는다. 한 번에 최대 50개.
- 설정 「내 글 다시 올리기」(기본 켬) + 마지막 결과 한 줄(「어제 3개를 다시 올렸어요」).

## 6. 우리 릴레이가 받는 것
- kind 10002 를 받는다(사람 글 규칙: 이야기 열쇠·`ravencoin` 또는 `ravenvault-relay` 표 있는 것만 — 기존 person_smells_bad 방식을 따름).
- 노드 지킴이 kind 8·30009 는 확인 서버 열쇠 것만(이미 9f4101e).

## 7. 설정 화면
- 데스크탑 설정 「일반」에 「릴레이 나누기」 카드: 켜기 스위치(기본 꺼짐), 상태 한 줄(「내 릴레이를 3명의 이웃과 나누고 있어요」/「바깥 주소가 없어 나누지 못해요 — 바깥 접속을 켜 주세요」), 이웃 릴레이 수, 「내 글 다시 올리기」 스위치와 마지막 결과, **접어 둔 「고급」**: 쓰는 릴레이 목록(지우기)·주소 더하기 칸.
- 폰·웹 설정: 「이웃 릴레이에서도 읽기」 스위치 + 접어 둔 「고급」(쓰는 릴레이 목록·더하기·지우기). 어르신 기준: 기본값이면 손댈 필요 없음.
- 사용자가 더한 주소도 2절 검사를 통과해야 한다.

## 8. 문구 정직하게
- 기능보다 앞선 문구(예: 「이 컴퓨터가 다른 가게의 공지도 같이 나릅니다. 가게가 늘수록 그물이 촘촘해지고, 남의 릴레이가 끊겨도 서로 붙습니다.」)는 실제 동작에 맞게 고친다: 릴레이 나누기를 켠 컴퓨터끼리만 서로 붙는다.

## 부록 — 데스크탑 구현 메모 (11-08, src-tauri/src/relay_share.rs · src/relay-share-ui.ts)
- 10002 태그 순서(데스크탑이 올리는 실제 모양): `["r", 내 wss 주소]`(켰고 자기 접속 시험 통과 때만) → `["r", N100]` `["r", primal]` `["r", nos.lol]` `["r", damus]` → `["t","ravenvault-relay"]`(내 주소가 있을 때만) → `["t","ravencoin"]`(늘). content 는 빈 글자. 표지(read/write) 없음.
- 내 주소 = 터널 주소 `https://…` → `wss://…/api/relay`. 10분마다 바뀌었는지 보고, 같아도 24시간마다 다시 올린다(14일 찾기 창 유지).
- 주소 검사(§2) 구현: `clean_relay_url` — 소문자 호스트·끝 `/` 지움으로 고른 뒤 비교·중복 제거. 사용자 이름(`@`)·`?`·`#`·`\`·`..`·`//` 도 거절. 접속 직전 DNS 가 공개 주소로만 풀리는지 한 번 더 본다(사설·루프백·CGNAT 등 거절).
- 글쓴이 릴레이(§4): 표지 없음·`write` 만, 사람당 2곳. 이웃 고르기(§3): 표지 없는 것만, 사람당 3곳. 기본 릴레이와 같은 주소는 뺀다.
- 「이웃 릴레이에서도 읽기」·「내 글 다시 올리기」는 기본 켬, 「릴레이 나누기」는 기본 꺼짐. 설정 파일 `relay-share.json`.
- 이웃 읽기 결과는 「없음」의 근거로 쓰지 않는다(이름표·팔로우·북마크 덮어쓰기 방지 — 기본 릴레이가 하나라도 답해야 함).
