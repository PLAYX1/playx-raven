# 라비 대화 흐름 정비 (2026-10-11)

기준 `4398376`(claude/rv-signed-lists-desktop). 실제 AI·송금·메인넷·대표 데이터는 쓰지 않았다(합성 하네스만).

## 무엇이 고장이었나 (수정 전 재현: `artifacts/ravi-chat-flow/before/`)

1. 「두 곳에 묻기」 + 열쇠 하나 → 「두 곳에 묻기는 서로 다른 회사의 열쇠가 둘…」 한 줄 뒤 `chatAgent` 가
   `ensureConsent()` 에서 **멈춤**. 카드가 떠 있는 동안 `raviRequestPending` 이 풀리지 않아 **다음 질문은 조용히 무시**됐다
   (같은 질문을 두 번 쳐도, 「돈 보내줘」를 쳐도 칸에 그대로 남음).
2. 「지금은 취소」 → 「정보 선택을 저장하지 않아 질문을 AI에 보내지 않았어요」 — 질문을 버림. 카드 문구(「모두 꺼도 일반 대화…」)와 모순.
3. 다크 모드에서 대화창(늘 밝은 판)의 「라비 안내 · AI 아님」 표지가 다크용 밝은 주황을 받아 대비 1.9:1.

## 바꾼 흐름

| 상황 | 이제 |
|---|---|
| 정보 선택 미저장 / 지금은 취소 | 백엔드가 개인 정보 없는 도구(`GENERAL` = 시세·노드 상태·화면 열기·홍보)만으로 바로 답. 카드는 답 아래 한 번만, 저장하면 마지막 질문 자동 재전송. 취소하면 이번 실행 동안 다시 안 뜸 |
| 열쇠 하나 + 두 곳에 묻기 | 단추를 감춤(쓸 수 있는 AI 가 둘 이상일 때만 보임). 경합으로 불려도 한 말풍선에 「AI가 하나만 연결돼 있어 바로 답할게요.」 + 답 |
| 「돈 보내줘」 | AI 로 보내지 않고 보내기 안내(「송금은 라비가 대신 하지 않아요…」 + 주소 확인·소액 먼저 + 「보내기 열기」). 주소와 「숫자 RVN」을 둘 다 적은 직접 지시만 기존 확인 화면 준비로 간다(확정은 사람이) |
| 「380만개면 부자순위 몇위야?」 | 정해 둔 정직한 답: 공개 순위표가 없어 순위는 모름 · 사용자가 말한 시세가 있을 때만 환산 · 주소 조회 방법. 열쇠 없으면 「AI 열쇠를 넣으면 더 잘 답해요」 |
| 열쇠 없음 + 안내로 못 답함 | 안내 + 같은 한 줄. 그 질문을 들고 있다가 열쇠 저장 직후 AI 로 자동 재전송 |
| 열쇠 저장(보류 질문 없음) | 연결 확인 성공 시 「연결됐어요 · 한 번 물어볼까요?」 + 개인정보 없는 시험 질문 단추 |
| AI 실패 | 원문은 버리고 고정 문구 넷 중 하나(열쇠 틀림 → 「열쇠 다시 넣기」, 한도·바쁨/연결 끊김 → 「다시 묻기」) |

## 공개 체인 조회 설계 (최소 구현)

- 기존 라비 도구에는 **남의 주소 잔액·분포를 보는 도구가 없었다**(`wallet_balance` 는 내 지갑, `addr_whose` 는 내 것인지 판정).
- 추가: `ravi_public_address(address)` — 기존 `publicbook::address`(blockbook.ravencoin.org) 재사용, 읽기 전용.
  - 인자는 **사용자가 질문에 적은 주소 하나**. base58·R 시작·26~35자만 통과.
  - 부르기 전 화면이 「이 주소만 보내요 · 지갑 주소 목록·주문 메모·고객 이름은 안 보내요」를 보이고, 사용자가 「공개 조회하기」를 눌러야 부른다.
  - 결과는 `{status, rvn, assets_unknown:true, source}` 숫자·고정값만. UTXO·txid·원문 문자열은 버린다.
  - **AI 도구 목록(NAMES)에는 넣지 않았다** — AI 가 혼자 주소를 골라 밖으로 보내지 못하게.
- 하지 않은 것(다음 단계 후보): 부자 순위표 계산(보유자 분포 데이터 출처가 없다 — Blockbook 은 순위 API 가 없음), AI 도구로의 노출(사용자 확인 단계를 AI 루프 안에 넣는 설계 필요), 자산 잔액.

## 시험

- `node scripts/check-ravi-chat-flow.mjs` — 실제 main.ts 대화 함수·ravi-chat.ts 를 VM 에서 (a)~(h) + 열쇠 흐름.
- `node scripts/check-ravi-chat-flow-browser.mjs` — dist 를 실제 Chrome 에서. 390·1440 × 라이트·다크, 대비 4.5:1, 가로 넘침 0, 대표 시나리오, 열쇠 흐름.
  `RV_CHAT_DIST=<수정 전 dist> … --before` 는 수정 전 화면을 남긴다.
- `cargo test --lib ravi_agent` — 미저장 동의의 일반 대화·준비 도구 차단·좁아질 때만 중단·공개 조회 투영·실패 문구 분류.
