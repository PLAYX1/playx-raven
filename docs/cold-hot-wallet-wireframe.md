# 지갑 화면 텍스트 와이어프레임

제품 검토용 초안. 화면 구현은 이번 범위 밖이다. 모든 금액·주소는 실제 정보 없는 자리표시자이며 시드 입력/표시 영역은 없다. 문구 키는 `cold-hot-wallet-copy.json`의 ko/en/ja/zh에 동일하게 정의한다.

```text
[내 지갑]                                            [받기]
전체 잔액 {확정 합계}      들어오는 중 {미확정 금액}
이동 중 {내부 이체 금액} — 전체 합계에는 한 번만 계산

┌ 용돈 지갑(핫) ────────────────────────────────────┐
│ 지금 쓸 수 있는 용돈 {사용 가능 잔액}               │
│ 수수료 포함 1회 {한도} · 하루 {한도}                │
│ 오늘 남은 한도 {금액} · 매일 00:00 (UTC+09:00)     │
│ 라비·게임·간식 결제는 용돈 지갑만 사용해요.          │
│ [용돈으로 보내기] [금고에서 옮기기] [한도 설정]      │
└───────────────────────────────────────────────────┘
┌ 금고(콜드) ───────────────────────────────────────┐
│ {잔액}                              감시 전용      │
│ {받을 주소}                         [주소 복사]    │
│ 보관 방식: 이 기기에 암호화 / 외부 기기             │
│ 평소에는 잔액과 주소만 확인해요.                    │
│ 금고 시드는 화면에 표시하지 않아요.                 │
│ [금고에서 큰 금액 보내기]                           │
│ (앱 내 보관일 때 항상 보이는 문구)                  │
│ 같은 기기에 시드가 있으면 완전히 못 열게 할 수는    │
│ 없어요. 기기가 악성코드에 감염되면 금고도 위험할     │
│ 수 있어요.                                         │
└───────────────────────────────────────────────────┘
[최근 내역: 용돈 결제 / 금고 이체 / 이동 중 / 확인 필요]
[모의 실행 표시 — 실제 돈은 이동하지 않아요]
```

**처음 설정:** 용돈 1회·하루 한도와 고정 기준 시간대를 선택한다. 자동 결제 범위를 확인한다. 금고 보관 방식은 (a) 이 기기에 암호화 보관, (b) 하드웨어 지갑·오프라인 서명 중 선택한다. (a)는 같은 기기 한계 문구, (b)는 지원 네트워크/기기 확인과 감시 전용 주소 등록 절차를 제공한다. 백업 준비 상태를 확인하기 전 실제 기능을 활성화하지 않는다.

```text
[용돈 부족 — 라비의 제안]
“용돈이 부족해요. 금고에서 얼마 옮길까요?”
[직접 금액 선택] [지금은 취소]
자동으로 옮기지 않아요. 다음 이체에도 승인이 필요해요.

          ↓ 사용자가 소유자 화면으로 이동

[금고에서 용돈으로 옮기기 — 거래 검토]
네트워크 {테스트넷}    출처 금고    목적 용돈 보충
받는 곳: 내 용돈 지갑 {전체 주소}
보낼 금액 {amount} + 수수료 {fee} = 합계 {total}
[취소] [비밀번호·생체 인증 후 이번 거래만 승인]
외부 기기: 기기에서도 금액·주소를 확인하세요.

          ↓ 인증 성공 · 요청 유효 · 내용 동일

[서명했어요. 아직 입금 확정이 아니에요.]
{거래 상태} [상태 확인]
입금이 확인되면 용돈 잔액을 갱신해요.
```

**한도 초과:** “용돈 한도를 넘어요. 금고에서 보낼 내용을 직접 확인하고 승인해 주세요.”를 표시하고 `[금고 송금 검토]`를 제공한다. 수신처를 보존하더라도 금고의 새 요청으로 만들고 금액·수수료를 다시 표시한다. 금고 보충이 일일 한도를 늘리지는 않는다.

**취소·만료·오류:** 취소는 서명 전까지 가능하다. 인증 대기 중에도 취소 버튼을 유지한다. 만료 후에는 새 검토부터 시작한다. 결과를 모르는 경우 “결과를 확인하지 못했어요. 다시 보내기 전에 거래 상태를 확인해 주세요.”라고 표시한다. 승인 버튼을 반복 눌러 재전송하지 않는다.

**접근성·개인정보:** 모달 제목에 초점을 옮기고 키보드 취소를 제공한다. 한도와 수수료는 색상만으로 구분하지 않는다. 주소 전체를 검토 화면에서 확인할 수 있게 하며 오류 알림은 비밀 없는 고정 문구로 읽어 준다. 금고 잔액/주소와 인증 UI의 내용은 AI 프롬프트에 전달하지 않는다. 번역 키 23개를 네 언어에 제공하며 실제 화면/기존 i18n 사전 연결은 후속 작업이다.
